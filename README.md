# Meu Primeiro Código em Java
Este é o meu primeiro programa em Java. O código solicita informações sobre duas pessoas e exibe esses dados de forma formatada.

### Funcionalidade
O programa pede o nome, salário, idade e sexo de duas pessoas.

Exibe esses dados no console com formatação adequada, como o salário com duas casas decimais.
### Tecnologias
Java: O código foi escrito em Java.
